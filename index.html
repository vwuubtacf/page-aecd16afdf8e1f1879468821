操作说明

从开通到连上，只需五步

若某一步失败，优先检查订阅是否过期、客户端是否为常见开源/主流工具，而不是反复重装系统。

常见问题

这一部分是本页的重点。把开通前最容易卡住的问题集中写清，便于你不来回跳转也能判断快柠檬是否适合自己。问答只描述流程与注意事项，不编造评测分数或节点规模。

快柠檬是什么？和普通 VPN 有何关系？

快柠檬是面向跨境访问的机场订阅型加速服务入口。行业里常把「机场」理解为可更新的节点订阅，把「VPN / 梯子 / 加速器」理解为你在设备上运行的客户端。对使用者来说，二者是一套：订阅负责提供线路列表，客户端负责加密握手与分流。

本站以官网形式汇总套餐、客户端下载与导入说明，方便对照自己的设备与场景，而不是把所有流量一刀切送进代理。

第一次使用快柠檬需要准备什么？

只需要能完成支付的账号、一台可安装客户端的设备，以及几分钟导入订阅的时间。建议先读套餐区，确认设备数量够用，再按「选套餐 → 复制订阅 → 下载客户端 → 导入 URL → 选节点连接」的顺序操作。

电脑与手机可以共用同一订阅，但会占用同时在线名额。公共电脑使用完毕应删除本地配置。

客户端应该选哪一款？本页能直接下载吗？

以本页「客户端下载」区域列出的平台为准。Windows 与 macOS 多用图形界面客户端，Android 与 iOS 则对应移动端工具，路由器用户需确认固件是否支持订阅导入。

快柠檬不在正文里另行填写第三方下载地址。若某个系统暂未列出，请等待该区域更新，或在工单中询问，而不是搜索来路不明的安装包。

订阅链接怎么导入？更新失败怎么办？

打开客户端的订阅或配置页，选择从 URL / 链接导入，粘贴用户中心的订阅地址，保存后手动更新一次。看到节点名称出现即表示成功。部分软件需要先允许本地网络或通知权限。

更新失败时依次检查：链接是否完整、套餐是否在有效期、系统时间是否准确、网络是否已能访问订阅域名。不要把订阅发到截图分享群，链接泄露后应立即重置。

基础版、旗舰版和团队版怎么选？

三档面向不同同时在线规模与流量习惯。个人轻度检索通常从入门档看起；多设备、流媒体或需要更优先支持时再对照更高档的说明。团队或工作室若要统一路由和专人沟通，再看团队向套餐。

价格、流量和设备上限只以套餐区展示为准，正文不复制数字，避免和结算页冲突。选定后如需升级，以用户中心规则为准。

流量用尽或到期后还能上网吗？

机场订阅一般按周期计量。流量用尽或到期后，客户端里的节点会无法握手或提示过期，需要续费、等待重置或调整档位。具体重置日与是否允许升级，请在用户中心查看，不要假设所有机场规则相同。

建议把客户端的流量统计打开，接近额度时减少大文件下载，把额度留给必须走代理的站点。

连接失败最常见的原因有哪些？

常见原因包括：订阅未更新、选了维护中的节点、系统时间偏差、公司防火墙拦截 UDP、以及客户端没有通知/VPN 配置权限。先换一条线路，再尝试切换协议或关闭再开客户端。

若所有节点均失败，优先检查订阅是否仍有效，而不是连续重装。iOS 需要系统允许添加 VPN 配置；Windows 偶尔需以管理员身份运行一次。

可以同时在电脑、手机和平板上使用吗？

可以，前提是不超过当前套餐允许的同时在线设备数。订阅本身通常能写入多台设备，真正限制发生在同一时刻的在线会话。出行时若临时多用一台设备，可先断开闲置终端。

家庭共享时建议约定谁在用 4K 流媒体，以免短时间耗尽流量。企业场景请直接看团队向套餐是否包含定制路由说明。

快柠檬能否用于流媒体或游戏加速？

这取决于你选择的套餐条目，而不是品牌名称本身。部分档位会写明流媒体解锁或游戏向优化，部分只覆盖基础浏览。请打开套餐区逐条阅读，不要把相邻档位的能力自行合并。

即便套餐写了相关能力，实际观感仍受当地网络、客户端分流规则和目标站点策略影响。把代理模式设为规则分流，比全局代理更不容易干扰国内应用。
